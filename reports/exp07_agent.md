## 约束与工具闭环

src/llm_client.py实现兼容Chat Completions的HTTP调用，读取根目录.env，进程环境变量优先。原真实运行模型标识来自旧记录，不保证其他账户同名模型可用。缺配置、网络超时、错误HTTP响应返回脱敏错误。

LLM解析景区、人群、时段、天数和冲突。未知景区不替换成已知景区；例如黄山未覆盖时，说明当前仅覆盖箱根、优胜美地、蓝山，并询问是否选择其中一个。缺景区提出完整问题；互斥天数要求请求用户裁定。缺日期等非必要信息不阻断已有景区检索。

模型可调用query_routes、query_advice，工具真实读取图谱并验证输入指纹。参数非法可按错误码修正，最多6轮、每轮6次调用。人群只匹配明确标签，不把未知默认为general。

程序核对路线ID、同一序列步骤编号、地点、原时刻、建议ID与doc_id，建议原文从工具回填。来源URL按照每条证据所属网页解析，不以复合文档首个URL代替所有页面。蓝山官方序列标source_order_only、候选活动标candidate_activity，最终结果明确不能当成必经行程。箱根换乘点与最终目的地分开。

## 七类场景

| 场景 | 应有行为 |
| --- | --- |
| 箱根亲子一天 | 查询路线与明确亲子建议，不承诺全路线适合儿童 |
| 箱根老人上午 | 仅上午片段，老人建议无匹配时如实说明 |
| 蓝山情侣两天雨天 | 返回候选活动与雨天建议，不编造情侣标签或完整两日路线 |
| 优胜美地避拥挤 | 可给避峰建议，无结构化路线时不给虚构步骤 |
| 缺景区 | 完整询问景区 |
| 一天/两天冲突 | 解释冲突并询问采用哪一项 |
| 未知黄山 | 明确未覆盖并说明支持范围 |

## 失败和局限

历史记录含空字符串工具参数错误及恢复、无效响应与重试、网络超时，分别保存失败和恢复文件；不以最终重跑抹去第一次失败。当前自由文本语义仍需人工复核，无距离、完整耗时、实时开放或完整人群适用证据。partial表示约束只能部分满足，不是100%规划成功。

# 本地更新和模型配置

先保存自己的修改，再更新代码。已经位于干净的项目仓库时执行：

```powershell
git switch main
git pull --ff-only origin main
```

如果有未提交修改，先查看git status并妥善提交或保存；不要强制覆盖。当前这台电脑以“实验”文件夹作为项目目录，后续在此目录操作。

推荐Python 3.12，新建环境并安装项目依赖：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env  # 仅第一次；已有.env不要覆盖
```

在本地.env填写自己的服务商配置：

```dotenv
LLM_API_KEY=你的接口密钥
LLM_BASE_URL=https://你的服务商提供的域名/v1
LLM_MODEL=你账号可用的模型标识
LLM_TIMEOUT_SECONDS=90
```

地址与模型标识必须按实际服务商填写，示例不能直接使用。模型须支持兼容Chat Completions的JSON输出和函数工具调用；不要将网页聊天地址或/models列表地址填入LLM_BASE_URL。此项目使用API密钥，不读取聊天软件登录状态。不要把密钥发到聊天或提交Git；.env已忽略。

先检查配置，再试一条真实请求：

```powershell
.\.venv\Scripts\python.exe src/exp07_agent.py --check-config
.\.venv\Scripts\python.exe src/exp07_agent.py --request "带孩子去箱根一天，有哪些路线和明确亲子建议？"
```

--check-config只检查配置字段，下一条才真实联网并可能产生服务商费用。重跑全部正式案例前，保存原始历史文件：

```powershell
Copy-Item data/outputs/agent_cases.json results/checks/exp07_pre_v3_live_cases.json
.\.venv\Scripts\python.exe src/exp05_07_verify.py --live
```

完整运行会真实调用模型并覆盖当前案例，失败也保留实际状态。尚未配置时可运行--offline完成数据重建、测试和历史提案复验；它不证明新模型运行成功。

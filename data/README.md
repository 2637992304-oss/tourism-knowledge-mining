# 数据目录约定

数据字段与编号的唯一依据是根目录的 `三人分工.md`，不要在本目录另建不同规范。

| 目录 | 存放内容 | 负责人 |
| --- | --- | --- |
| `raw/` | 原始文本、来源记录；保留原文，不被清洗结果覆盖 | DHT |
| `processed/` | `scenic_registry.json` 和公共清洗语料 `corpus.jsonl` | DHT |
| `outputs/` | 实体、路线、共指、建议、图谱和 Agent 场景正式结果 | 各实验负责人 |

当前已有3景区18篇v1正式语料、实体和共指结果，并已整合YZH的4条路线。FYH接管实验5/6/7后当前有21条条件建议、v4融合图谱及本轮deepseek-flash真实LLM案例；旧v2日志保存在results/checks/history。来源与运行说明见根目录README及results/checks中的各实验交接文件。示例和合成协议测试不计入正式语料或真实LLM案例。

公共语料首版标记为 `corpus_version: "v1"`。实验输出先引用同一份语料，再进行交接；语料变更须升级版本并重新生成受影响的结果。

共享时保留必要的来源信息，去掉个人账号、令牌等无关信息。大体积或不适合直接入库的文件，由 DHT 在本说明中登记获取方式、文件名与版本，避免组员拿到不同数据。
